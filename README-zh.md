# 图形物理仿真实验

本仓库包含图形物理仿真课程的四个实验作业：
- 实验1：刚体仿真
- 实验2：流体仿真
- 实验3：可变形体仿真
- 实验4：课程最终项目 — 流体-固体耦合

每个实验包含必做的基础实现以及若干可选的扩展（bonus）。

## 编译与运行

```sh
xmake run lab1
xmake run lab2
xmake run lab3
xmake run lab4
```
